## 验证边界

- 浏览器尺寸为自动化视口模拟；未执行真实手机软键盘、设备字体或系统辅助技术人工验收。
- 中文输入法检查使用 composition 事件，仍需真实设备输入法补验。
- 未运行生产后台、多设备同步、真实模型、认证、导入导出、部署或 40 万 token 历史压力测试。
- 本地保存不等于后端持久化；断线与上下文省略均为演示状态，不证明生产恢复或 token 算法。
- 无后端业务 API、数据库迁移、OpenAPI 或正式文件格式变更。
