# ModernTavern 本地交互原型

## 范围与运行

本原型基于 PRD v0.3，用于验证阅读、输入、会话、连接配置、候选、历史编辑、分支与六套传统色的交互。它使用模拟数据，不调用模型，不提供认证、后端持久任务或跨设备同步。API Key 输入仅供原型交互，独立保留在当前页面会话内；无需填写真实凭据。

运行基线：Bun `1.3.13`、Nuxt `4.1.3`。`bun.lock` 固定实际依赖，不使用其他包管理器锁文件。

```sh
bun install --frozen-lockfile
bun run dev --port 3100
bun run typecheck
bun test
bun run build
HOST=127.0.0.1 PORT=3101 bun run preview
```

开发／预览仅监听本机。首页 `/`，组件主题预览 `/themes`。页面顶部的试管图标打开独立演示场景。没有生产 API、OpenAPI 或数据库变更。

Nuxt CLI、Nitro 预览、测试和类型检查均通过 Bun 运行。`vue-tsc` CLI 在 Bun 下依赖的 `fs.readFileSync` 模块加载钩子不生效；`scripts/typecheck.cjs` 直接复用官方 Vue／Volar 类型检查程序接口，不将 `.vue` 文件降级为通用声明，也不跳过模板检查。

## 演示路线

1. 阅读预置的“雨落在旧书店”，切换已有候选；箭头只切换，独立“重新生成”才创建候选。
2. 输入并发送，观察接收确认前草稿保留、确认后清空。生成中可以写下一段，但不能再次发送或修改上下文。
3. 停止保留部分内容；“继续故事”新增 AI 消息；“重新生成”保留原候选并选中新候选。
4. 消息更多菜单支持原位编辑、独立分支、删除本条及后续；删除前展示范围。点击候选编号可打开管理菜单，直接删除未选中候选而保持当前回复不变；删除最后一个候选会移除对应 AI 消息。
5. 会话入口提供新建、搜索、切换、重命名和删除；生成中的会话删除前先取消，已有独立分支保留。
6. 点击顶部带图标的“连接配置”按钮进入管理；按钮文案不会随模型 ID 改变，未选择配置时仍可打开。连接浮框中填写名称、API Base URL、可留空的 API Key 与模型 ID。Key 默认遮蔽，可切换显示，仅留在当前页面内存；保存后本页可重开编辑，刷新后需重新输入。
7. 模型 ID 旁的“测试连接（刷新模型）”模拟 GET `/models`，显示加载、成功、失败重试或空列表；成功后刷新模型选项，保留当前手填 ID。展开“原型演示响应”选择成功、失败或空列表，不会发起真实请求。修改地址或 Key、取消编辑时取消旧测试。
8. 外观设置包含六主题、亮暗／跟随系统、阅读式／气泡式、字号、宽度和平滑显示。偏好仅在当前浏览器保存。
9. 演示场景提供慢首字、发送未接收、空候选失败、部分输出失败、断线提示、其他会话完成和上下文省略。断线只模拟界面反馈，不制造真实后端能力。

未发送草稿、阅读位置、会话和设置按浏览器保存。刷新会中断本页模拟任务并保留已有文字。恢复初始数据只清理本原型的数据；不清空其他站点或浏览器数据。原型默认会话名称使用当前浏览器本地时间模拟，生产版仍遵守 PRD 的后端宿主机时区规则。

## 验证方法

```sh
# 先完成构建并启动上面的本地预览服务，再运行：
MT_BASE_URL=http://127.0.0.1:3101 \
CHROME_BIN=/opt/google/chrome/chrome \
MT_ARTIFACTS=/tmp/moderntavern-browser-check \
bun scripts/browser-check.ts
```

浏览器脚本通过 Playwright 启动独立 Google Chrome 上下文，不读取用户浏览器资料。Chrome 可执行文件路径由 `CHROME_BIN` 指定，不下载浏览器。默认截图与结果写入临时目录；可通过 `MT_ARTIFACTS` 指定其他输出目录。

自动化覆盖十二套色板对比度、24 个主题／模式／尺寸组合、系统模式变化、主要剧情流程、草稿保护、焦点、窄屏、断线提示与刷新恢复。真实手机软键盘、生产服务、多设备一致性、真实 token 预算及 40 万 token 历史性能均不由这些结果证明。

## 已确认的原型补充决策

- 浏览器本地保存模拟数据，并提供确认后的恢复初始数据。
- 发送在模拟接收确认后清空草稿；失败保留，生成失败不恢复已发送内容。
- 主动取消有修改的历史编辑时先确认，确认后丢弃；未保存跳转提供保存、放弃、取消跳转。
- 默认青磁、跟随系统、阅读式、平滑输出；字号 17px、正文宽度 800px，窄屏受可用宽度限制。

这些补充是本轮用户确认或批准计划中的原型行为，不表示真实后端相关技术问题已经解决。

## 连接配置补充验收

可空 Key 的模拟 GET /models 请求描述遵守空值不带 Authorization、非空使用 Bearer 的规则。Key 与持久化配置结构分离；删除连接和恢复初始数据会清除对应页面内存凭据。模型列表仅为模拟演示，不代表真实服务商可访问或模型推理可用。
